---
name: Product SEO generation and approval
description: Market-aware rules for AI-generated localized product descriptions and manual activation.
---

Generate localized SEO drafts from suitable active products in the same marketplace first. Use external web search only when the internal catalog has no suitable reference. Every AI draft remains unapplied until an administrator reviews and activates it; for an unsaved product, activation is staged until that product is saved. Activating a draft updates only the chosen market/language translation. When reopening a product, load its saved localized description and SEO sources into the same editable panel; changes require an explicit save.

**Why:** The user wants to improve existing products manually while keeping control over factual accuracy, avoiding unreviewed copy on the storefront, and being able to revise activated SEO without generating it again.

**How to apply:** Keep generation available for both existing and new products, show external sources in the draft preview, and never silently replace an existing localized description.
