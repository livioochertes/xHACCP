This campaign has distinct light and navy cover variants. If a reference to “the other cover” is ambiguous, compare the selected canvas visual or ask before exporting; the intended cover for the current homepage adaptation is the light version shown in the selected frame.

**Why:** Both variants share the event photo, French copy, and similar export dimensions, so assuming the color variant from relative wording led to attaching the wrong files.

**How to apply:** Before preparing or replacing campaign exports, verify the light/navy variant against the selected visual. Do not substitute the same-sized counterpart.
