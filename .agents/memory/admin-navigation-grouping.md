---
name: Admin navigation grouping
description: Product rationale and constraints for the Admin primary navigation groups.
---

Keep the Admin navigation grouped as:
- Dashboard (standalone)
- Catalog
- Sales & operations
- Marketing & promotions
- Administration

Place WMS under Administration because this page contains PAI-to-WMS integration settings. Keep the marketplace selector independent of the navigation groups.

**Why:** The WMS destination configures an administrative integration, while the marketplace selector controls a separate, persistent market context.

**How to apply:** Reorganize labels or groups without changing existing destinations, market filtering, or WMS settings behavior.
